3: A=1. System Overview | B=
4: A=Summary | B=Spend Tickets + Money to attempt a second copy of an owned pet.
EN: Duplicate / VN: Nhân Bản.
5: A=Core Logic | B=Select an Unused pet → pay Tickets + Money → roll Duplicate success.
Success: create one Clone; original and Clone become Used.
Failure: no Clone; original stays Unused. No donor.
6: A=Apex Attempt | B=20 Tickets + Money per attempt. Each attempt has a 50% chance to create 1 Clone.
7: A=2. Player Flow | B= | K= 
8: A=1. Open Machine | B=Show Unused pets first.
Used pets are greyed out with "Already duplicated".
9: A=2. Select Original | B=Select one owned Unused pet from the line or inventory.
Following pets cannot be selected.
10: A=3. Confirm UI | B=Display original, Clone preview, success chance, Ticket cost, Money cost and hatch time.
Show: "This pet can only be duplicated successfully once."
11: A=4. Confirm Duplicate | B=Recheck ownership, location, Unused status, RB ≥ 20, DuplicateExclude, valid price, funds and egg space.
If any check fails → show reason; no charge.
12: A=5. Start Duplicate | B=Lock original → consume Tickets + Money → roll success once.
Success: mark original Used and create Clone egg. Failure: keep original Unused; no egg.
Save payment and result together, then unlock original. One pending Duplicate per player. | M= 
14: A=3. Rules | B=
15: A=Unlock Rule | B=Unlock at player Rebirth 20.
16: A=Ownership | B=Player must own the selected pet when confirming.
Previously owning the species does not qualify.
17: A=Can duplicate Secret / Limited | B=Yes.
18: A=Excluded Pets | B=Block pet IDs listed in DuplicateExclude. Default = [].
Adding an ID does not remove existing Clones.
19: A=Duplicate Status | B=Unused: can duplicate.
Used: cannot duplicate.
Save status on each pet, not the account.
20: A=Starting Status | B=Existing pets at release = Unused.
Newly created pets = Unused, except Clones = Used.
21: A=Status Transfer | B=Keep status through steal, trade, storage, following, reconnect, upgrade, rebirth and room change.
Mutation, Weather and level changes do not reset Used.
22: A=Fusion Result | B=Input pets are consumed. The newly created Fusion result is Unused and can duplicate.
23: A=Original After Duplicate | B=On success, keep level, mutation, weather, size, locks and other attributes. Only Duplicate status changes to Used.
On failure, original stays unchanged and can retry.

34: A=Ticket Cost | B=TicketCost = DuplicateTicketCost[rarity], paid once per attempt.

35: A=Money Cost | B=MoneyCost = OriginalSpeciesBaseShopPrice × 2.
Consume Money on every attempt, whether success or failure.

Success: create 1 Clone. Failure: no Clone; original stays Unused.
No pity. Each retry pays the full Ticket + Money cost.
