7: A=1. Overview
8: A=A recurring event where playerts submit pets to earn Collector Tokens, then spend tokens freely in the event shop. Submitting a higher-quality pet (mutation tier, weather effect) earns more tokens per contract. 

The limited event pet is a purchasable shop item, not a milestone gate.

 | H=            
9: A=Goal | B=- Introduce Limited Time Pet (1/account).
- Swapable with EventCollector7 for event duration (ex: 14 days).
- Contracts are the hard gate (inputs), Fuse Machine is the reward outlet (semi-deterministic + RNG).
- Contracts do NOT grant rewards directly. They only increase milestone progress. | H= 
10: A=Core Loop | B=Check contracts → acquire/upgrade target pets → submit → earn tokens → spend in shop.

13: A=Rule Name | B=Rules
14: A=Daily Contracts | B=- Generate 6 Contracts per day.
- Each Contract requires submitting specific pet IDs (randomized daily based on epoch).
- Completing a Contract:
- Consumes required pets.
- Adds +1 Event Progress.
- Grants no direct reward. | F=3.0
